========================================================================
腰痛防止リマインダー (Webカメラ着席判定版)
========================================================================

PC作業中の長時間の座りっぱなしを防ぐため、Webカメラの映像から動きを監視し、
30分以上連続して着席している場合に警告ダイアログを表示する
タスクトレイ常駐型アプリケーションです。

------------------------------------------------------------------------
■ 1. 準備：Pythonおよび必要ライブラリのインストール
------------------------------------------------------------------------
環境が入っていないまっさらなWindows 10 / 11 の場合は、まず以下の手順で
Python環境を構築します。

【1】 Pythonのインストール
1. Python公式サイト (https://www.python.org/downloads/) にアクセスし、
   「Download Python」 をクリックしてインストーラーをダウンロードします。
2. ダウンロードしたファイルを実行します。
3. 【重要】 インストール画面の最初にある 「Add python.exe to PATH」 に
   【必ずチェックを入れてから】 「Install Now」 をクリックしてください。
   ※チェックを忘れると、コマンドプロンプトで python や pip コマンドが使用できません。

【2】 コマンドプロンプトの確認
キーボードの [Windowsキー] + [R] を押し、 cmd と入力して Enter を押し、
コマンドプロンプトを開いて以下を実行します。

    python --version

バージョン番号（例: Python 3.11.x 等）が表示されれば成功です。

【3】 必要なライブラリのインストール
コマンドプロンプトで以下のコマンドを実行し、依存ライブラリを一括インストールします。

    pip install opencv-python pystray pillow


------------------------------------------------------------------------
■ 2. アプリケーションの導入手順
------------------------------------------------------------------------
以下の 【方法A】 または 【方法B】 のどちらかの手順でファイルを準備します。

--- 【方法A】 GitHubからクローンする ---

1. Gitがインストールされている場合は、作業したいフォルダで以下を実行します。
    git clone https://github.com/ユーザー名/back-pain-reminder.git
    cd back-pain-reminder

2. (Gitが入っていない場合) GitHub上の本リポジトリページ右上にある
   「Code」 ボタン → 「Download ZIP」 をクリックして解凍します。


--- 【方法B】 ソースコードをコピペして作成する ---

1. PC上の任意の場所に新しいフォルダ（例: back_pain）を作成します。
2. フォルダ内で右クリック → 「新規作成」 → 「テキスト ドキュメント」 を選択します。
3. ファイル名を back_pain_reminder.py に変更します。
   ※拡張子 .txt が .py に変わるように変更してください。
4. back_pain_reminder.py をメモ帳等で開き、プログラムのソースコードを貼り付けて保存します。


------------------------------------------------------------------------
■ 3. 起動方法
------------------------------------------------------------------------
1. コマンドプロンプトを開き、プログラム（back_pain_reminder.py）がある
   フォルダに移動します。
    cd C:\パス\フォルダ名

2. 以下のコマンドを実行してプログラムを起動します。
    python back_pain_reminder.py

3. タスクトレイ（画面右下の「^」ボタン内など）にアイコンが表示されれば
   正常に起動しています。


------------------------------------------------------------------------
■ 4. 便利な使い方：PC起動時に自動開始（スタートアップ登録）
------------------------------------------------------------------------
PC起動時に自動で立ち上がるようにしたい場合の手順です。

1. キーボードの [Windowsキー] + [R] を押し、 shell:startup と入力して Enter を押します。
   （スタートアップフォルダが開きます）
2. そのフォルダ内で 右クリック → 新規作成 → ショートカット を選択します。
3. 項目の場所に以下のように入力します（ファイルパスは環境に合わせて変更してください）。

    pythonw.exe "C:\パス\back_pain_reminder.py"

   ※ python.exe の代わりに pythonw.exe を使うと、黒いコマンド画面を出さずに裏で起動できます。

4. 「次へ」を押し、名前を「腰痛防止リマインダー」などにして「完了」をクリックします。


------------------------------------------------------------------------
■ 5. 終了方法
------------------------------------------------------------------------
タスクトレイの丸アイコンを右クリック → 「終了」 を選択してください。
